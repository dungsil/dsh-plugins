# @dungsil/dsh-plugin-yoonmoon

[yoonmoon](https://github.com/amondnet/yoonmoon)의 한국어 글다듬기 스킬 6개를 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)에 제공하는 플러그인

## 실행 모델

스킬을 불러오면 대화 에이전트가 원문과 요청 조건을 `yoonmoon` 도구에 전달합니다. 도구는 번들에 포함된 스킬과 참고 자료를 사용해 별도 모델 호출로 글다듬기·진단을 수행하고 결과를 반환합니다. 전과정 윤문은 여섯 스킬의 지침과 참고 자료를 한 호출에 포함합니다. 대화 모델과 대화의 추론 수준은 변경하지 않습니다.

**상황별 모델** 플러그인과 함께 사용하면 **설정 → 상황별 모델 → 윤문**에서 모델과 추론 수준을 지정할 수 있습니다. 설정은 윤문 플러그인의 `provider`·`model`·`reasoningEffort`에 저장합니다. **보조 모델 따르기**는 공통 보조 모델을 사용하고, 보조 모델이 없거나 **대화 모델 따르기**를 선택하면 대화 모델로 별도 호출합니다. 상황별 모델 플러그인 없이도 대화 모델을 기본으로 사용합니다. 자동 추론 수준은 모델 기본값을 사용하며, 대화의 추론 수준은 상속하지 않습니다.

윤문 모델에는 도구에 전달한 원문과 요청 조건만 보내며 대화 이력이나 파일 접근 도구는 제공하지 않습니다. 파일 입력과 결과 저장은 대화 에이전트가 처리합니다. 후속 요청에는 필요한 이전 결과와 조건을 다시 전달해야 합니다. 원문은 선택한 모델 제공자에게 전송되며 별도 호출 요금이 발생할 수 있습니다. 호출을 취소하거나 플러그인을 다시 로드하면 진행 중인 작업도 취소되며, 5분을 넘긴 호출과 불완전한 출력은 오류로 반환합니다.
