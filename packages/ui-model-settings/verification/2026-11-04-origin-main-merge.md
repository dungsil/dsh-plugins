# origin/main 병합 검증

검증일: 2026-11-04, Windows 환경에서 실행했습니다.

## 병합 범위

로컬의 자동 저장과 중국어 번역을 유지했습니다. 원격의 추론 수준 설정과 DSH 공통 Menu 선택 UI를 함께 반영했습니다.
모델을 바꾸면 추론 수준 지정을 해제합니다. 추론 수준만 바꾸어도 즉시 저장하며, 저장이 실패하면 값을 다시 조회합니다.

## 자동 검증

- [x] 모델 설정 API 테스트 6개와 UI 테스트 30개가 모두 통과했습니다.
- [x] 영어, 한국어, 중국어 번역 키의 일치 여부와 빈 번역문 유무를 검사했습니다.
- [x] DOM 테스트에서 세 언어로 전환하여 모델과 추론 수준 선택 UI의 문구를 확인했습니다.
- [x] `model-settings`, `ui-model-settings`, `ui-worktree` 빌드와 타입 검사가 통과했습니다.
- [x] 충돌을 해결한 세 파일의 형식 검사와 `git diff --check`가 통과했습니다.

Node.js `24.21.0`과 저장소에 설치된 DSH `0.2.1-rc.5` 패키지를 사용했습니다.
전체 린트는 오류 없이 통과했으며, 이번 병합에서 수정하지 않은 코드의 경고 8건이 남았습니다.

## 전체 검사에서 남은 제한

- pnpm 실행과 의존성 설치는 로컬 데이터베이스 또는 저장소 잠금 파일의 접근 오류로 실패했습니다. 설치된 도구를 직접 실행하여 위 항목을 검증했습니다.
- 전체 형식 검사는 기존 `ui-worktree` 설정 소스에서 실패했습니다. 충돌 해결과 관계없는 파일은 정리하지 않았습니다.
- 마켓과 패키지 계약 테스트는 `packages/request-secret/package.json`이 없어 실패했습니다. 릴리스 테스트는 Windows 심볼릭 링크 생성 권한 때문에 실패했습니다.
- 워크트리 테스트는 33개 중 30개가 통과했습니다. 서버 테스트 3개는 Windows 역슬래시 경로와 Git의 슬래시 경로가 달라 실패했습니다. 임시 검사에서 전환 요청의 경로 표기를 맞추면 서버 테스트 7개가 모두 통과했습니다. 원본 테스트는 수정하지 않았습니다.

## 실제 DSH 세션 검증

이 작업에서는 실제 GUI를 조작하지 않았으므로 다음 항목을 완료로 표시하지 않습니다.

- [ ] 최신 플러그인을 실제 세션에 설치하거나 갱신한 뒤 활성화합니다.
- [ ] 실제 세션이 최신 빌드를 불러왔는지 확인합니다.
- [ ] 설정 화면에서 모델과 추론 수준을 바꾸고 자동 저장 동작과 기존 DSH UI와의 일관성을 확인합니다.
- [ ] 실제 세션에서 영어, 한국어, 중국어로 각각 전환하여 문구를 확인합니다.
