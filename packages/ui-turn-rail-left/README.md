# 왼쪽 턴 레일

공식 DSH Chat의 턴 레일을 화면 왼쪽으로 옮깁니다. 미리보기는 레일 오른쪽으로 펼칩니다.

## 사용

1. 이 플러그인을 설치하고 활성화합니다.
2. 턴이 두 개 이상인 대화를 엽니다.
3. 대화 영역의 가로 여백을 제외한 너비를 900px보다 넓게 확보합니다.

레일을 누르면 공식 Chat이 해당 턴으로 이동합니다. 키보드 탐색, 미리보기, 이전 기록 불러오기, 현재 턴 표시도 공식 구현을 그대로 사용합니다.
좁은 대화 영역에서 레일을 숨기는 기존 동작은 바꾸지 않습니다. 플러그인을 끄면 원래 오른쪽 배치로 돌아갑니다.

## 호환 범위

DSH 0.2.1-rc.5의 공식 Chat 구조를 기준으로 작성했습니다. 현재 공식 API에는 레일 위치 설정이나 전용 Slot이 없습니다.
플러그인은 `shell.overlay` Slot에 스타일만 추가하며, 공식 Chat의 CSS 클래스 세 개에 의존합니다.
DSH 업데이트로 클래스가 바뀌면 위치 변경이 적용되지 않을 수 있습니다. 이때 공식 레일은 기존 위치에서 작동합니다.
패키지의 DSH 버전 범위는 저장소의 0.2.x 정책을 따르지만, 이후 버전의 화면 배치는 별도 확인이 필요합니다.

위치는 UI 언어 방향과 관계없이 물리적인 왼쪽입니다. 대화 내용이나 세션 설정은 변경하지 않습니다.
추가 DOM 관찰자, 타이머, 전역 이벤트 수신기는 설치하지 않습니다. Slot이 해제되면 React가 스타일을 제거합니다.

## 개발 검사

```sh
pnpm --filter @dungsil/dsh-plugin-ui-turn-rail-left build
pnpm --filter @dungsil/dsh-plugin-ui-turn-rail-left typecheck
pnpm --filter @dungsil/dsh-plugin-ui-turn-rail-left test
```

단위 테스트는 배포 파일, Slot 등록, 위치 스타일을 검사합니다. 실제 화면의 배치와 공식 탐색 동작은 DSH에서 확인해야 합니다.
